# ADR-001：编排先用自研循环，不硬上 LangGraph

## 背景

项目运行在 Python 3.8；`langgraph` 当前版本没有 3.8 发行版。JD 要求 LangGraph/Coze 经验。

## 决策

先用“显式工具循环 + 状态字段”把业务跑通，保留迁移到 LangGraph 的接口；不为了框架而重写。

## 理由

- 业务规则（订单归属、券上限、退货窗口）与编排解耦，换框架不影响规则。
- 现有循环可测试、可降级、可离线。
- LangGraph 迁移可以按节点 1:1 映射，风险可控。

## 代价

- 简历关键词缺失；需要额外做迁移图/Coze 工作流补证据。
- 没有 checkpoint/人工中断的原生支持。

## 后续

Python 3.10 环境用 `StateGraph` 重构；工具层与评测集不变，用同一套 eval 对比。
