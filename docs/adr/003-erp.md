# ADR-003：ERP 用适配器 + mock 服务，而不是把 HTTP 写进工具

## 背景

JD 要求商品/订单/物流/ERP 对接；直接在每个工具里写 `httpx` 会导致超时/重试/幂等散落。

## 决策

- `HttpCommerceClient` 统一封装 HTTP：超时、重试、幂等键、鉴权、错误映射。
- mock ERP 提供商品/订单/物流/退货/券端点。
- `CommerceToolkit` 可选走 ERP；失败回退本地 JSON，并写 `erp_fallback` 审计。

## 理由

- 工具层只关心“取到什么数据”，不关心传输细节。
- 本地模式保证无 ERP 也能演示。
- 幂等键与错误码可以独立测试。

## 代价

- 目前是 mock，不是真实 ERP 字段/对账。
- 回退可能造成短暂数据不一致，生产需要补偿任务。

## 后续

真实沙箱、字段映射、对账、补偿、全链路 trace、熔断。
