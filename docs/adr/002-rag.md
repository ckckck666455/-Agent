# ADR-002：RAG 先用 TF-IDF 向量基线

## 背景

FAQ 规模 25 条；JD 要求 RAG。引入 embedding 模型/向量库会增加部署与下载成本。

## 决策

用 sklearn `TfidfVectorizer` 字符 1-2 gram + 余弦相似度做检索基线，保留 `search(query) -> matches` 接口；生产替换 dense retriever。

## 理由

- 零模型下载、零 API 成本，离线可跑。
- 25 条 FAQ 上字符 n-gram 召回稳定。
- 可先建立 Hit@1/Hit@3/MRR 评测，再换模型对比。

## 代价

- 不是语义检索；同义表达可能召回失败。
- 没有 rerank、引用粒度有限。

## 后续

bge-m3 / text-embedding-3-small + pgvector/FAISS；hybrid + rerank；补 groundedness 评测。
