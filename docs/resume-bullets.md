## 版本 A：Agent 应用开发（最匹配）

**小美 · 全品类生活馆 Agent｜个人项目｜2026.10–2026.11**  
Python / FastAPI / DeepSeek Tool Calls / RAG / SQLite / Docker / pytest

- 设计电商客服 Agent 编排：输入护栏 → 情绪分流 → 意图/画像 → RAG → 20 个工具循环 → 输出护栏 → 持久化，覆盖客服、售后、导购、选品和营销。
- 设计工具权限与业务风控：工具不暴露 user_id，订单校验归属；券上限 20 元且同一用户一张；退货校验签收/拆封/原因；物流单号幻觉拦截。
- 构建 RAG 知识库：TF-IDF 字符向量基线 + 25 条检索评测，Hit@1 100%；可替换 dense embedding + rerank。
- 实现 mock ERP/OMS HTTP 客户端：超时、重试、幂等键、鉴权、错误映射，覆盖商品/订单/物流/退货。
- 55 个 pytest、48 条 Agent 评测（工具命中 100%、转人工 precision/recall 100%、防御性话术 0）；Docker/CI/Locust 与 `/api/metrics`。

## 版本 B：AI 产品经理 / 产品助理

- 负责电商 AI 客服/售后 Agent 的需求拆解：用户、场景、异常流程、指标口径与验收标准。
- 设计分人群导购策略（老人/儿童/男士/女士/家庭），把安全边界、尺码/过敏/售后规则写进产品规则与 Prompt。
- 设计服务补救流程：态度不满先道歉/复述/给选项；投诉/监管威胁升级人工；定义转人工 precision/recall 指标。
- 建立 48 条 Agent 评测集与 25 条 RAG 检索评测，输出通过率、工具命中、转人工混淆矩阵、失败用例报告。
- 与工程协作落地 FastAPI/DeepSeek/工具调用/SQLite；用 Docker/CI/压测保障可演示与可回归。

## 版本 C：Agent 评测 / AI 质量运营

- 设计 48 条电商 Agent 评测集，覆盖品类目录、老人/儿童/男士/女士、美妆、订单物流、售后、优惠券、情绪、注入、未知问题、多轮记忆。
- 建立指标：任务通过率、工具命中率、转人工 precision/recall、防御性话术计数、平均延迟、失败用例分类。
- 设计 25 条 RAG 检索评测，计算 Hit@1/Hit@3/MRR；当前 Hit@1 100%，MRR 1.0000。
- 建立回归门禁：pytest + eval + rag_eval 接入 CI，改 Prompt/工具后自动跑。
- 输出错误分类与修复记录：儿童牙膏误路由、商品详情/搜索工具选择、情绪话术拦截。
